Mini-Galaxy — Rendering Style

The small network diagram in the top-right of the panel. How should it behave?

SOURCES ● employer   ● committee   ● candidate
Drag to pan · scroll to zoom · hover to focus

A — Live D3 force simulation (animated)

Nodes animate into position on open, repel each other, settle naturally. Same engine as the main galaxy — just scoped to pattern nodes. Interactive: drag, zoom, hover to highlight. Feels alive.

Pros

  • Consistent with main galaxy UX
  • Handles any number of nodes gracefully
  • Reuses existing galaxyBuild / galaxyForces

Cons

  • ~100ms simulation settle time on open
  • More complex — needs own simulation lifecycle

Static · hover to highlight node

B — Static hierarchical layout (tier columns)

Nodes pre-positioned in tier columns: Employer | Committee | Candidate. No animation, no physics. Instant render, always legible. Hover highlights connected edges.

Pros

  • Instant — no simulation wait
  • Always readable left-to-right flow
  • Much simpler implementation

Cons

  • Feels less alive than the main galaxy
  • Multi-hop committee chains stack vertically
