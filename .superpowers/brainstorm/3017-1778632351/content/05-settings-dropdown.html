Behavior
  • Desktop: hover or click ⚙ Settings ▾ opens the dropdown. Click outside / Esc closes.
  • Mobile: drawer shows the two items inline (no nested menu — phones don't need it).
  • Take a tour → calls startTour(). Welcome modal does not reappear (only "Configure" can reset that, if we ever want a "reset onboarding" button).
  • Configure → opens the existing <Settings/> page (current behavior, just renamed in the menu).
  • The current tab === "settings" id stays internal — only the user-facing label changes.
