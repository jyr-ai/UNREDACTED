KEY FACTS — no extra DB work needed
  • politicians.bioguide_id already populated — direct key into Congress.gov API
  • getMemberDetails(bioguideId) already exists in congressGov.js — returns photo URL + committees
  • Photo URL comes from depiction.imageUrl on the Congress.gov member object
  • Non-Congress politicians (presidential candidates, retired) may have no bioguide_id — panel gracefully degrades to name + party only
  • New route needed: GET /api/congress/member/:bioguideId — one-liner wrapping existing getMemberDetails
