Architecture C — Approach & Component Map
NEW SERVER COMPONENTS
NEW ROUTE
GET /api/galaxy/node/:id?cycle
Returns 1-hop subgraph (edges + nodes) + dated transactions (contributions + committee_transfers) for any node ID. Single endpoint works for all 500 nodes.
NEW ROUTE
GET /api/congress/member/:bioguideId
One-liner wrapping existing getMemberDetails() in congressGov.js. Returns photo URL (depiction.imageUrl), chamber, party, state, committees.
EXISTING
GET /api/galaxy/patterns/:id
Already exists. Returns pattern narrative, explanation, node_ids, evidence edges. No changes needed.
NEW FRONTEND COMPONENTS
NEW
MiniGalaxy.jsx
Self-contained D3 force simulation. Accepts nodes[] + edges[] from the node endpoint. Renders at ~220px height. Zoom + drag. Reuses galaxyBuild / galaxyForces.
NEW
ContributionTimeline.jsx
Sorted dated event list. Accepts mixed receipts[] + transfers[]. Amber dot = individual receipt, blue dot = committee transfer.
NEW
PatternNarrative.jsx
AI text block + severity badge + "also appears in" chip list. Only renders when the clicked node appears in funding_flow_patterns.node_ids.
NEW
PoliticianProfile.jsx
Photo + congress.gov metadata block. Renders only when node.kind === 'candidate' and node.bioguide_id is non-null. Fetches in parallel with node endpoint call.
REFACTOR
GalaxyDrawer.jsx
Refactored to wire the four components above. Calls /api/galaxy/node/:id on any click. Renders MiniGalaxy + [PatternNarrative if flare] + [PoliticianProfile if candidate] + ContributionTimeline.
